  <br />

  한라시스템솔루션즈는 제주에 기반을 둔 외주 개발사로서 공공·기업의 업무 환경에 맞는 정보시스템을 설계하고 구축합니다. 제주 지역은 방문 협의가 가능하며, 도외 프로젝트는 온라인 미팅과 원격 협업으로 진행합니다.

  - **제주 외주 개발 및 맞춤형 시스템 개발** — 요구사항과 업무 흐름에 맞는 시스템 설계·개발
  - **공공·기업 웹·업무 시스템 구축** — 웹서비스, 관리자 시스템, 업무 플랫폼 구축
  - **API·데이터 연동 및 업무 자동화** — 내·외부 시스템 연계, 데이터 이관, 반복 업무 자동화
  - **기존 시스템 고도화 및 유지관리** — 기능 개선, 안정화, 운영·기술지원
  - **AX 전환 및 AI 업무 적용** — 검색, 분류, 문서 처리 등 목적에 맞는 AI 기능 적용

  수행 절차는 요구사항 분석 → 설계 → 구축 → 연동 → 검수 → 운영 지원으로 진행합니다.

  적용 가능 업무는 공공 접수·승인·통계, 기업 업무관리, 데이터 연동·자동화 등이며, 이는 수행 실적이 아닌 적용 가능 업무 예시입니다.
</details>
